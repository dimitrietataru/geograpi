# Geography Open API

[![build](https://github.com/dimitrietataru/geograpi/actions/workflows/build.yml/badge.svg)](https://github.com/dimitrietataru/geograpi/actions/workflows/build.yml)

## Getting started
* From Visual Studio
```
Start the 'docker-compose' project
```

* From CLI
``` powershell
docker compose up
```
